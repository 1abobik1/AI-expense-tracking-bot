# CLAUDE.md

Бот учёта семейных расходов: Telegram-бот с ИИ-агентом (Go) и веб-панель главы семьи (React). 

## Куда смотреть

| | |
|---|---|
| `backend/` | Go: бот, ИИ-агент, REST API. Правила — [backend/CLAUDE.md](backend/CLAUDE.md) |
| `web/` | панель на React + Vite + TS. Правила — [web/CLAUDE.md](web/CLAUDE.md) |
| `deploy/cloudflare/` | Worker: `wrangler.toml`, своя точка входа `worker.mjs`, сборка конфига D1 |
| `docs/` | архитектура, агент, безопасность, запуск, API — для людей |
| `Makefile` | все команды: `make help` |

## Два варианта запуска одного кода

- **Docker / VPS:** `cmd/server`, файл SQLite, бот через polling.
- **Cloudflare:** `cmd/worker` собирается TinyGo в wasm, база D1 (тоже SQLite), ИИ через binding Workers AI, бот через webhook.

Любое изменение бэкенда должно собираться в обоих вариантах: `make test` проверяет и сборку Worker.

## Общие правила

- **Перед сдачей:** `make test` и `make lint` должны быть зелёными. Pre-commit хук (`make hooks`, `.lefthook.yml`) сам форматирует и линтит файлы коммита. Если менялся промпт или разбор сумм — ещё `make eval` (нужен ключ в `.env`).
- **Комментарии** короткие, по-русски, объясняют «почему», а не «что». Пересказ имени функции не нужен.
- **Секреты** живут только в `.env` (он в `.gitignore`) и в secrets Worker. В код и документацию не попадают.
- **Не запускать Docker с прод-токеном бота в режиме polling:** он снимает вебхук Cloudflare. Для локальных проверок `TELEGRAM_MODE=off`.
- **Коммиты и push делает владелец репозитория.** Агент их не делает без явной просьбы.
- **Документацию обновлять вместе с кодом:** короткий `README.md`, детали в `docs/`.
