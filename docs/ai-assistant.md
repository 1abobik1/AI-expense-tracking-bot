# Как использовался ИИ-ассистент

Проект написан с Claude Code. Порядок работы:

1. **Сначала план и вопросы.** Обсудили архитектуру, БД, фронтенд, доступ к боту и панели, требование изоляции. Ассистент спрашивал там, где решение было за мной, и предлагал не расширять задание (мульти-семьи), а закрыть реальную дыру: одобрение участников.
2. **Прототип самого рискованного места.** До написания приложения проверили, что Go в WebAssembly с D1 укладывается в бесплатный Cloudflare. Позже бандл вырос до 4.3 МБ. Ассистент нашёл причину через граф зависимостей линкера (`http.DefaultTransport`) и сжал бандл до 2.2 МБ без перехода на TinyGo.
3. **Модель выбрана измерением, а не на глаз.** Eval на 42 трудных фразах прогнан по восьми бесплатным моделям, расход взят из API. Провалы слабых моделей превратились в код: сленг и десятичная запятая разбираются до модели.
4. **Опыт своих проектов.** Подход к бесплатной модели взят из VocabTGBot (JSON по образцу вместо `json_schema`, отключённые «размышления» Gemma 4), структура кода — из service-mani.
5. **Проверка вживую.** Тесты на каждый слой. Docker и `wrangler dev` проверены с поддельными Telegram и LLM, прод на Cloudflare — с настоящей моделью. Панель проверена по скриншотам на десктопе и телефоне, в светлой и тёмной теме.
